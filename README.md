## Overview
This repository contains the system architecture redesign, technology evaluation, and modular project setup for **FitFlow**, a cross-platform, AI-driven fitness application.

## Recommended Tech Stack Summary
- **Mobile Frontend**: React Native (Cross-platform support, shared codebase, rich animation support)
- **Backend Framework**: Node.js + Express (Asynchronous API layer)
- **Database**: Firebase Firestore (Real-time data synchronization for workouts/social interactions)
- **Authentication**: Firebase Authentication (MFA, social logins, secure token-based auth)
- **Push Notifications**: Firebase Cloud Messaging (FCM)
- **AI & Computer Vision**: TensorFlow Lite (On-device model processing) and Google ML Kit (Food/nutrition recognition)

## Repository Structure
- `/frontend`: React Native mobile application setup
- `/backend`: Node.js API services and business logic
- `/ai-service`: AI microservices and TensorFlow Lite models
- `/docs`: High-level architecture diagrams, comparison matrices, and Architecture Decision Records (ADRs)
